# Resume — Mourya Vignesh Manduva

GitHub Pages site for my resume. Includes links to my LinkedIn, GitHub, and LeetCode profiles.

## Files

- `index.html` — Resume landing page and PDF viewer
- `Mourya_Vignesh_Manduva_Resume.pdf` — Resume PDF

## GitHub Pages

1. Create a GitHub repository named `resume`.
2. Upload `index.html` and `Mourya_Vignesh_Manduva_Resume.pdf`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.

The page will be available at:

`https://YOUR-USERNAME.github.io/resume/`
